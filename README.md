# 🌍 Wanderlust  (Dharmsanchara)

A full-stack travel platform that allows users to explore, list, and review travel destinations. Integrated with **TomTom Maps API** for real-time location visualization and secure user authentication with Passport.  

## 🚀 Live Demo  
🔗 [Wanderlust App](https://project-wander.onrender.com/listings)  

---

## ✨ Key Features  
- 🔑 **User Authentication** – Login, Logout, and User Profile Section  
- 📝 **CRUD Operations** – Add, Edit, and Delete Listings  
- ⭐ **Review System** – Add and Delete Reviews  
- 🔒 **User Data Security** – Password Hashing & Encryption  
- 🗺 **Interactive Maps** – Integrated with **TomTom API** for location visualization  
- 📈 **Trending Destinations** – Based on user views  
- 📧 **SOS Email Alerts** – Send emergency messages to registered contacts in case of help  
- 🧑‍🤝‍🧑 **Guide Booking** – Users can book travel guides for personalized experiences  

---

## 🚀 Future Scope  
- 📍 **AI-powered Recommendations** – Suggest destinations based on user preferences and travel history  
- 💳 **Integrated Payments** – Secure booking and payment gateway for guides and services  
- 🤝 **Community Features** – Travel groups, forums, and chat system for better engagement  
- 📱 **Mobile App** – Extend the platform with a cross-platform mobile application  
- 🌐 **Multi-language Support** – To make the app accessible to global users  


---

## 🛠 Tech Stack  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** Passport.js  
- **Maps Integration:** TomTom Maps API

## ⚡ Installation & Setup  

1. Clone the repo  
   ```bash
   git clone https://github.com/tsujit74/project
   cd root directory
````

2. Install dependencies

   ```bash
   npm install
   ```

3. Add a `.env` file

   ```env
   CLOUD_NAME=draaug605
CLOUD_API_KEY=
CLOUD_API_SECRET=

MAP_API_KEY=

ATLASDB_URL=
SECRET=

EMAIL_USER=
EMAIL_PASS=
   ```

4. Run the server

   ```bash
   npm start
   ```
